1. Fundamentos Conceptuales (Perfil Lectura / Escritura - R)

En programación, una variable es una ubicación reservada en la memoria RAM del computador asociada a un identificador simbólico (nombre). Esta ubicación almacena un valor de un tipo de dato específico que determina qué operaciones se pueden realizar sobre él y cuánta memoria ocupa. Los tipos de datos primitivos más comunes son: • int (Entero): Representa números sin parte decimal, tanto positivos como negativos (ej. -5, 0, 42). • float (Punto Flotante): Representa números reales con parte decimal o exponencial (ej. 3.14159, -0.5). • bool (Booleano): Representa un valor de verdad lógico, restringido a únicamente True (Verdadero) o False (Falso). • str (Cadena de Texto): Secuencia inmutable de caracteres delimitada por comillas simples o dobles (ej. "Studify", 'Python').

3. Explicación Narrativa y Analogía (Perfil Auditivo - A)

Imaginen que la memoria RAM de la computadora es como una gran estantería llena de cajas de almacenamiento en un centro logístico. Cuando declaras una variable en tu programa, es como tomar una caja vacía, pegarle una etiqueta con un nombre claro (como precio_producto) y guardar dentro un objeto determinado. Si guardas un entero, colocas un contador rígido. Si guardas un texto, pones una carta escrita. Lo crucial que debes recordar al escuchar esta explicación es que el tipo de dato actúa como el "molde" de la caja: no puedes intentar realizar operaciones aritméticas con una caja etiquetada como texto sin antes hacer una conversión explícita. Por ejemplo, al sumar la palabra "10" con el número 5, el lenguaje te advertirá que los tipos no son compatibles.
